# 项目简介

## 核心功能
- 电影/剧集/综艺推荐
- 热度排序
- 分类筛选
- 用户登录注册
- 收藏
- 评论
- 评分
- 个人中心管理
- 分类标签管理
- 最新电影展示
- 评论互动

## 适用场景
- 在线影视平台
- 个人影视偏好分析
- 影视内容推荐服务

## 技术特点
- 使用 Django 作为后端框架，实现用户管理、数据存储和业务逻辑
- 基于 MySQL 数据库存储用户数据和电影信息
- 采用 HTML、CSS 和 JavaScript 进行前端页面设计和交互
- 支持协同过滤算法，为用户提供个性化推荐
